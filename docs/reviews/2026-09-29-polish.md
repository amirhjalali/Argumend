### e. Topic titles: done

`9d2e2e1`.

Legacy maps were titled "X — Argument Analysis", and flagship maps had no suffix at all.

The cause: `app/topics/layout.tsx` set a plain string title, which resets the root `"%s | ARGUMEND"` template for every page under /topics/. The layout now carries `{ default, template }`, and legacy maps pass their title alone. Results:

- "Climate Change | ARGUMEND"
- "Will AI cause mass unemployment? | ARGUMEND"
- "Climate Change — Diagram | ARGUMEND"

The same bug was in `app/blog/layout.tsx` and `app/for-educators/layout.tsx` (`62c0b21`). All 86 essays, every blog category and tag page, and every worksheet went out with no suffix. Worksheets now end "— for teachers | ARGUMEND".

The visible h1s are unchanged.
