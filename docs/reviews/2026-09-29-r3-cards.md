# Round 3: library cards, reflection, paste and home on phones (2026-09-29)

Branch `r3/cards` off `ux/round2-2026-09-29` (2e22a00). Fixes issues 6, 7 and 11 and the phone

## What changed

1. **Maps library cards** (`app/topics/*`, `app/saved/SavedClient.tsx`). A card is the map's
   question, its first crux question (italic), and a quiet line "Policy · Turns on three
   questions". Gone from cards: "Evidence still divided / largely converges / still thin" and
   "N pillars, M evidence cards". "Start here" and /saved use the same card body
   (`app/topics/MapCardText.tsx`). The first crux comes from generated summaries, not topic files:
   `scripts/regen-summaries.ts` now writes `firstCrux` into `data/topicSummaries.json` (the text the
   map page heads crux 1 with) and a new `data/argumentTopicSummaries.json` for the three flagship
   maps (crux #1 as the map page ranks it, plus how many cruxes there are). Two tests fail if either
   drifts. The library search also matches the question and the first crux. The `/topics` title is
   now "Maps — 159 contested questions" (`MAP_COUNT`), not "150+".
2. **Reflection** (`components/topic/CruxReflection.tsx`). After a tap, it shows that crux's
   "What would settle it" line (the same `SettleAnswer` the crux sheet uses) and an "Open this
   question" link to `#crux-…`. The link opens the fold itself as well, because `hashchange` does
   not fire when the hash is already set. Options wrap in full (the `line-clamp-2` is gone).
   Still local-only.
3. **One follow-up question** (`lib/changedQuestion.ts`). "Did this change what you thought you
   were arguing about?" with Yes / A little / No, on every map and in the paste result. The paste
   result used to offer Yes/No only.
4. **Paste result** (`components/paste/*`). "Open the map at this crux" (the page's one rust
   action) sits directly under the crux box, not in the next-step block. Evidence card text is held
   to 3 lines, with a "Read more" / "Show less" toggle that appears only when the text is cut.
   "Closely related" shows once, under the map's claim; the duplicate `RelatedMaps` section is
   removed.
5. **Home on phones** (`components/home/HomeLanding.tsx`). The source order is now doors first,
   then the stat. From md the grid still places the stat in its right-hand column, so desktop is
   unchanged.
