# Deep citation audit, batch 08 (2026-11-10)

Maps: `obesity-personal-responsibility`, `assisted-dying-euthanasia`, `sugar-tax-effectiveness`.

Method: every `sourceUrl` was requested in this session (curl; PDFs read with `pdftotext`) and each number, name, date and quotation in the card was compared with the page. Where the publisher refused the fetch (NEJM, Wiley, Elsevier, Sage, OUP, Health Affairs, AJPH, CDC, PubMed), the claim was checked against a hosted copy named below: the PMC full text, an archive.org snapshot of the same URL, or the Europe PMC / Crossref abstract for the same DOI. No URL was written that was not loaded.

Totals: 29 cards checked, 20 corrected, 0 replaced, 0 ids changed, 0 sides changed. One card (`paternalism-autonomy`) has no source by design and was not checked. The three `keystone_fact` sources were checked and stand.
