# Disagreement Diagnosis eval rubric

Score each fixture 0–2 on:

- Positions: no invented opponent, steelman acceptable
- Common ground: supported or correctly absent
- Type: empirical/causal/definition/value not swapped
- Crux: load-bearing or correctly absent
- Evidence: no invented sources
- Resolution: operational, not “more debate”
- Honesty: no independent-verification claim, no winner

A run fails if any case invents a source or swaps value for empirical.
